### ⚠️ Environment gotcha (important for next session)
`package-lock.json` pins `registry.npmmirror.com`, which returns **HTTP 403** in this environment. A plain `npm install` **fails**. Use:
```bash
npm install --registry=https://registry.npmjs.org/ --package-lock=false
```
If typecheck/build suddenly fail with `Cannot find type definition file for 'node'` / `'vite/client'`, it means `node_modules` is missing or partial — reinstall with the command above. **Recommended follow-up:** regenerate a clean `package-lock.json` against npmjs.org and commit it.

## 8. How to Run Locally

```bash
git clone https://github.com/lanrcaz/SLASH-CRM.git
cd SLASH-CRM
git checkout claude/review-launch-platform-pzrGX
npm install --registry=https://registry.npmjs.org/ --package-lock=false
npm run dev            # Vite prints a localhost URL (default :3000, see vite.config.ts)
```
`.env` is unconfigured (Supabase URL/key blank in `.env.example`); the UI renders fully on mocks without it. Note: a browser's `localhost` cannot reach a dev server running inside the cloud sandbox — run locally to view.
